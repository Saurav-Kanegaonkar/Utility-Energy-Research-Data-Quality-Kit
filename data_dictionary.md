# Data Dictionary

| Table | Grain | Purpose |
|---|---|---|
| `utility_programs.csv` | Utility program | Program metadata, tool ownership, completeness, savings, participation, and verification timing |
| `source_observations.csv` | Source observation | Primary and secondary source evidence used to update fields and document confidence |
| `quality_checks.csv` | QA check | Open and resolved data quality issues with severity, affected records, owner, and procedure step |
| `research_requests.csv` | Research request | Client and internal research support requests with due dates, audience, question, source need, and status |
| `data_tool_updates.csv` | Data-tool update task | Maintenance backlog for populating, reconciling, documenting, and publishing program records |
| `program_quality_queue.csv` | Utility program | Ranked QA and update priority queue |
| `tool_update_plan.csv` | Data-tool update task | Ordered maintenance plan with blocker and next-step context |
| `research_request_triage.csv` | Research request | Prioritized request queue with response guidance |
| `stakeholder_brief_pack.csv` | Program brief | Written summary components for stakeholder-ready communication |

# Analysis Plan

## Objective

Create a repeatable data quality and research support workflow for utility energy program data tools.

## Steps

1. Generate deterministic synthetic source tables for utility programs, source observations, quality checks, research requests, and data-tool update tasks.
2. Roll up source confidence, citation gaps, open QA checks, affected records, pending update volume, blockers, and stale verification dates at the program level.
3. Score each program into a QA priority queue so analysts can decide what to validate, update, document, or publish with a caveat.
4. Score research requests by program quality risk, due date pressure, source need, and audience.
5. Convert the highest-risk programs into short stakeholder brief components with evidence and a recommended next step.

## Decision Use

The outputs help an analyst decide which data-tool rows need attention first, which research requests need caveats, and which findings are ready to summarize for nontechnical stakeholders.

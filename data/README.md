# Data Sources

All CSV files in this folder are deterministic synthetic data generated by `scripts/score_operating_data.py`.

The data is modeled on utility energy-efficiency and demand-side-management research operations, where analysts maintain program data tools, reconcile primary and secondary sources, document definitions, review QA checks, and support stakeholder research requests.

## Files

- `utility_programs.csv`: Program metadata, data-tool assignment, completeness, savings, participation, and verification dates.
- `source_observations.csv`: Source-level observations from utility filings, surveys, client spreadsheets, web research, analyst interviews, and benchmark studies.
- `quality_checks.csv`: Data quality checks for stale values, citation gaps, unit conversion issues, definition mismatches, duplicate rows, and benchmark outliers.
- `research_requests.csv`: Client and internal requests tied to reports, articles, webinars, data pulls, and analyst questions.
- `data_tool_updates.csv`: Tool maintenance tasks with pending row counts, blockers, completeness, and next steps.

The rows do not represent real utility performance, customer data, proprietary research content, or client work.

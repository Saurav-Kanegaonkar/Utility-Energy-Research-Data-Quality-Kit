# Data Sources

Synthetic source-style data for utility energy research, data-tool maintenance, and energy-efficiency program analysis.

- `entities.csv`: 36 utility program records.
- `daily_metrics.csv`: 5,040 utility program-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
